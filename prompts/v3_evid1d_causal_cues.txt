You extract candidate causality cues from narrative text for a later event/scene pipeline.

Input format:
- Each paragraph is on one line.
- Paragraph ids appear as [P12].

Return ONLY a valid JSON object:
{
  "causal_cues": [
    {
      "pid": 12,
      "span": "exact substring from the paragraph",
      "start_char": 0,
      "end_char": 10,
      "candidate_type": "causality",
      "label": "short free-text causal relation label",
      "cue_span": "optional explicit cue such as because/so/therefore",
      "cause_text": "short cause-side paraphrase or exact local phrase",
      "effect_text": "short effect-side paraphrase or exact local phrase",
      "rationale": "optional short reason"
    }
  ]
}

Allowed candidate_type value for this pass:
- "causality"

What to include:
- Evidence that one state, event, intention, condition, discovery, speech act, or background fact explains, enables, blocks, triggers, motivates, or results in another.
- Explicit markers such as because, so, therefore, since, as a result, due to, when used causally.
- Implicit but text-supported causal links when the paragraph clearly presents explanation, consequence, reason, prevention, enabling condition, or result.

Rules:
- Maximize recall. This is a candidate extraction stage; later stages will validate and attach causal links to events.
- Do not use a fixed causal subtype taxonomy. The label field is a short free-text hint, not a controlled category.
- span must be an exact substring of the paragraph text and should be the local evidence for the causal link.
- start_char and end_char are optional but must be correct if supplied.
- Do not extract cast/place/time/object/action/goal as separate records in this pass.

Text:
