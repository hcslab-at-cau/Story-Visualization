You extract candidate goal / intention / motivation cues from narrative text for a later event/scene pipeline.

Input format:
- Each paragraph is on one line.
- Paragraph ids appear as [P12].

Return ONLY a valid JSON object:
{
  "goal_cues": [
    {
      "pid": 12,
      "span": "exact substring from the paragraph",
      "start_char": 0,
      "end_char": 10,
      "candidate_type": "goal",
      "label": "short free-text goal cue label",
      "owner_span": "optional cast/agent span that appears to hold the goal",
      "target_span": "optional object/place/cast/action target span",
      "goal_text": "short paraphrase of the inferred goal",
      "rationale": "optional short reason"
    }
  ]
}

Allowed candidate_type value for this pass:
- "goal"

What to include:
- Explicit desires, intentions, plans, purposes, needs, obligations, attempts, preferences, avoidance, fear-driven objectives, or inferred motivations.
- Goal cues usually belong to a cast/agent, but record the cue even when the owner is implicit or uncertain.

Rules:
- Maximize recall. This is a candidate extraction stage; later stages will judge whether each goal is valid and attach it to events/entities.
- Do not use a fixed goal subtype taxonomy. The label field is a short free-text hint, not a controlled category.
- Do not invent a goal unsupported by the paragraph. It is okay to include a cautious goal_text if the span strongly implies it.
- span must be an exact substring of the paragraph text and should be the evidence cue, not the whole paragraph.
- start_char and end_char are optional but must be correct if supplied.
- Do not extract cast/place/time/object/action/causality as separate records in this pass.
